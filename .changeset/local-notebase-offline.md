feat(notebase): save vocabulary to a local offline notebase with flashcards

Dictionary results can now be saved to a local notebase on this device instead of the account-gated cloud Notebase. Users pick a folder once (Chrome/Edge) or fall back to the extension's built-in storage (Firefox) with JSON export/import; no login or paid plan is required. The local notebase page adds table/kanban/gallery views, card templates, and FSRS spaced-repetition review with Again/Hard/Good/Easy ratings, bury, suspend, and rollback. The cloud Notebase code paths are retained but no longer used for saving.
