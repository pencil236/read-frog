feat(notebase): add SRS settings, review session details, and a sidebar entry

Each notebase now has an editable SRS settings dialog (daily new/review limits, desired retention, learning steps, leech threshold, short-term scheduling and fuzz), reachable from both the notebase detail page and the review page. The review page gains keyboard shortcuts (Space to reveal, 1-4 to rate), a progress bar, per-session rating counters, and a review history list. A Notebase entry was added to the options sidebar for direct access.
